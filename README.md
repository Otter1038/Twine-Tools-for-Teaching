# Teaching Demonstration

This repository powers a GitHub Pages site for a teaching-focused demonstration project. The landing page is designed to share course materials, assignments, and instructional resources in a clean, accessible format.

## What is included
- A polished homepage for the Teaching Demonstration site
- Links to assignment, syllabus, lecture, and tool resources
- GitHub Pages deployment support through a workflow

## Publish the site
1. Push these files to GitHub.
2. Open the repository settings and enable GitHub Pages.
3. Choose the GitHub Actions deployment method if prompted.
